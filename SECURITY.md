# Security

Do not commit API keys, Qwen web-session tokens, credential files, uploaded videos, generated reports, or private media.

Supported secret paths:

- environment variables such as `QWEN_OPENAI_API_KEY` and `QWEN_FREE_API_TOKEN`
- local untracked files referenced by `QWEN_FREE_API_TOKEN_FILE`

Report security issues privately to the repository maintainer. Do not open a public issue with tokens, private footage, or exploit details.
